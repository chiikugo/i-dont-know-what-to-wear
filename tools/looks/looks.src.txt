# ═══════════════════════════════════════════════════════════════════════════════
#  tools/looks/looks.src.txt — every runway look in the app, one per line
# ═══════════════════════════════════════════════════════════════════════════════
#
#  This is the SOURCE of the whole catalog. After editing it, run:
#
#      npm run looks
#
#  which fetches/crops any new photos into public/looks/ and rewrites
#  src/data/looks.generated.ts (the file the app actually imports).
#  Lines starting with "#" are comments.
#
#  WHERE THE PHOTOS COME FROM
#  Real runway, street-style and museum photos on Wikimedia Commons, published
#  under Creative Commons licences (CC BY, CC BY-SA, CC0). The app credits the
#  photographer and licence under every photo. (firstVIEW / Vogue Runway / WWD /
#  ARCHIVE.pdf photos are copyrighted, so the app links to those sites instead of
#  showing their pictures — see src/data/shows.ts.)
#
#  ── THE FORMAT ─────────────────────────────────────────────────────────────────
#
#  id | Commons file | section | show | position | moods | formality | garments
#
#   id         unique name for the look, e.g. kors10-016. Pieces are named after
#              it ("kors10-016/jackets-blazer"), and saved outfits remember those
#              names — so avoid renaming ids once people have saved looks.
#   Commons    the file's exact title on commons.wikimedia.org (without "File:").
#   section    w = womenswear, m = menswear, u = both.
#   show       a key from src/data/shows.ts (which designer / season / links).
#   position   where the person stands in the ORIGINAL photo, in % of its size:
#                  centre-x , top-of-head , bottom-of-feet
#              e.g. "55,18,89" = body centred 55% across, head at 18% down,
#              feet at 89% down. (Tip: open the photo, eyeball it on a 10% grid.)
#              Museum pieces shot alone use "50,0,100" (the whole photo).
#   moods      1–2 of: minimal classic relaxed street edgy romantic sporty
#   formality  1 = loungewear … 3 = smart casual … 5 = black tie
#   garments   the garments to cut out of the photo, separated by ";"
#
#  ── ONE GARMENT ────────────────────────────────────────────────────────────────
#
#    category[/type-or-length].fit.colour=Title[@crop]
#
#    e.g.  jackets/blazer.slim.grey=Grey flannel double-breasted blazer
#          skirts/midi.baggy.forest=Green leather handkerchief skirt
#          accessories/bag.regular.white=White box bag@42-62,38
#
#   category   shirts tshirts sweaters hoodies jackets pants skirts dresses
#              shoes accessories
#   type       jackets:     blazer coat leather bomber denim puffer cape fur vest utility
#              pants:       tailored denim leather cargo leggings track shorts
#              hoodies:     pullover zip
#              dresses:     jumpsuit (otherwise give a length)
#              shoes:       heels boots sneakers loafers dress sandals
#              accessories: bag belt hat sunglasses scarf tights
#   length     skirts & dresses: mini midi maxi
#   fit        slim regular baggy
#   colour     a colour name from src/data/types.ts (white, camel, navy, print…)
#   @crop      OPTIONAL. Normally the crop comes from a preset per garment kind
#              (see PRESETS in src/data/crops.ts). Override it when needed:
#                @y0-y1           vertical span in % of the PERSON
#                                 (0 = top of head, 100 = soles), e.g. @6-62
#                @y0-y1,x         …and centre the crop at x% of the plate
#                                 (for a bag held to one side), e.g. @40-60,35
#                @y0-y1,x,w       …and make it w times wider
#                @full            use the whole photo (museum pieces)
#
#  ── ADDING A LOOK ──────────────────────────────────────────────────────────────
#   1. Find a photo on commons.wikimedia.org with a CC BY / CC BY-SA / CC0 licence,
#      at least ~1500 px tall, with the whole person in frame.
#   2. Add a line below (copy a similar one), and a show in src/data/shows.ts if
#      it's a new collection.
#   3. Run `npm run looks`, then `npm test` (checks every piece has a valid crop,
#      an image and a licence).
# ═══════════════════════════════════════════════════════════════════════════════
